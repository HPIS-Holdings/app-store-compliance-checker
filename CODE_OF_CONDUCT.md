# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be kind, assume good intent, and focus on what is best for the community. Harassment, insults, and personal or political attacks are not tolerated.

Report unacceptable behavior privately to the maintainers via [GitHub's private reporting](https://github.com/HPIS-Holdings/app-store-compliance-checker/security/advisories/new) or by contacting HPIS Holdings at https://hpisholdings.com. All reports are reviewed and handled confidentially. Maintainers may remove, edit or reject contributions and temporarily or permanently ban contributors who violate this code.
